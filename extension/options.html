Ekstensi ini aktif di srikandi.arsip.go.id saat membuka halaman Registrasi Naskah Keluar.

Provider AI

Buat di platform.claude.com → API Keys. Kunci disimpan hanya di browser ini (chrome.storage.local).

Default memakai Kenari (https://kenari.id/v1, model deepseek-v4-1-flash). Kompatibel dengan endpoint OpenAI chat/completions lain: Ollama (http://localhost:11434/v1), LM Studio, Groq, dsb. Endpoint harus mengizinkan CORS.

Halaman Tujuan

Panel tampil bila URL halaman memuat nilai ini (default: registrasi-naskah-keluar).
