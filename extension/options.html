📄 SRIKANDI Naskah AI — Pengaturan

Ekstensi ini aktif di srikandi.arsip.go.id saat membuka halaman Registrasi Naskah Keluar.

Provider AI

Buat di platform.claude.com → API Keys. Kunci disimpan hanya di browser ini (chrome.storage.local). Lewat proxy: isi Base URL https://proxy.anda.com (tanpa /v1) dan aktifkan ANTHROPIC_API_KEY di proxy.

Request dialirkan lewat proxy backend Anda (lihat backend/README.md) yang menyimpan API key AI di server. Isi token aplikasi yang diberikan admin — bukan API key AI. Bisa juga diarahkan langsung ke endpoint OpenAI-compatible lain (Ollama http://localhost:11434/v1, LM Studio, Groq, dsb.) dengan key sendiri — endpoint itu harus mengizinkan CORS.

Halaman Tujuan

Panel tampil bila URL halaman memuat nilai ini (default: registrasi-naskah-keluar).
